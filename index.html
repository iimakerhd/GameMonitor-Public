A free companion app for League of Legends players

GameMonitor runs on your own PC, next to the League client, and shows a live dashboard in your browser: champion select, builds, runes, summoner spells, player profiles and item suggestions. No ads, no payments, no account.

What it looks like

Features

Champion select dashboard

Phase, timer, bans, both rosters, who is hovering what, whose turn it is. Pick, ban and lock in from the dashboard, request trades and swaps, choose a skin, and read or send pregame chat.

Runes and summoner spells

A full rune page editor and a summoner spell picker that only offers the spells that exist in the current game mode.

Champion Builds

Look up any champion and see the items, boots, rune pages and spells that have been winning, by game mode, queue, lane and (in ranked queues) rank. It always shows how many games the numbers come from.

Player profiles

Rank, last 20 games, most played champions, main role and champion mastery for the players in your game, or for any Riot ID you type in.

In-game item suggestions

Ideas for what to buy next, based on your champion, the enemy team's champions and what they have built. They are suggestions, not instructions.

Alerts and missions

Notifications for champ select phases and your turn, a read-only missions panel, and a notice when a low priority queue applies.

Automation

GameMonitor can automatically start a queue search and accept a found match. It does this by recognising the on-screen buttons of the League client and clicking them for you; it does not use the League Client API for this. It stops when the League client is closed, pauses itself during a game, and can be paused at any time with the Pause Automation button on the dashboard.

Everything else that changes something in your client (locking in a champion, setting spells, importing a rune page, trades and swaps, sending a chat message) only happens when you click it on the dashboard.

Rocket League

GameMonitor also detects a found match in Rocket League and brings the window to the front. That part does not use any Riot data.

How it works

  1. Download and start it. GameMonitor is a Windows program. Start it, then open the dashboard address it prints in your browser (http://localhost:5000 on the same PC).
  2. Read the notice. The first time you open the dashboard you see the disclaimer and a choice about sharing anonymous game statistics. Sharing is off unless you turn it on.
  3. Queue as usual. In the lobby you can look up builds and player profiles. GameMonitor follows the League client's own phases: lobby, search, match found, champion select, in game.
  4. Champion select. The dashboard mirrors champion select and lets you act on it, the same way clicking in the client would.
  5. In game. A scoreboard and item suggestions appear from the local game data.
  6. On your phone (optional). The dashboard also opens on a phone on the same Wi-Fi. Other devices need an access key that is shown on the PC; this PC does not need one.

Everything runs on your own PC. GameMonitor reads the League client that is already running on your machine. It does not read game memory, change game files or play the match for you.

Which Riot technologies it uses

We want to be fully open about this, including the parts that Riot does not officially support.

1. League Client API (local, not officially supported)

GameMonitor talks to the League client running on the player's own PC through its local API. It uses these endpoint families:

What forEndpoints (local client)Read or act
Client phase and queue/lol-gameflow/v1/gameflow-phase, /lol-gameflow/v1/sessionRead
Ready check state/lol-matchmaking/v1/ready-checkRead
Champion select/lol-champ-select/v1/session, /lol-champ-select/v1/session/timer, /lol-champ-select/v1/skin-carousel-skinsRead
Pregame chat/lol-chat/v1/conversations and its participants and messagesRead, and send a message when the player writes one
Players/lol-summoner/v1/summoners, /lol-summoner/v1/summoners/names, /lol-summoner/v1/alias/lookup, /lol-summoner/v2/summoners/puuid/{puuid}Read
Profiles and statistics/lol-ranked/v1/ranked-stats/{puuid}, /lol-match-history/v1/products/lol/{puuid}/matches, /lol-match-history/v1/games/{gameId}, /lol-collections/v1/inventories/{id}/champion-masteryRead
Runes and spells/lol-perks/v1/styles, /lol-perks/v1/perks, /lol-perks/v1/pages, /lol-perks/v1/currentpage, /lol-perks/v1/inventory, /lol-game-data/assets/v1/summoner-spells.jsonRead, and create or edit rune pages when the player saves one
Notices/lol-leaver-buster/v1/* (low priority queue), missions endpointsRead

When the player clicks something on the dashboard, GameMonitor sends the same request the client would send for that click: hover or lock a champion or ban (/lol-champ-select/v1/session/actions/{id}), change spells or skin (/lol-champ-select/v1/session/my-selection), request or answer a trade or swap (/lol-champ-select/v1/session/trades, position-swaps, pick-order-swaps), swap with the ARAM bench (/session/bench/swap), save a rune page (/lol-perks/v1/pages) and send a chat message. GameMonitor never chooses for the player and only acts when the client says the action is available.

We know this API is not officially supported and that Riot may ask us to change or remove any of these uses. We are registering the product so that Riot can review them.

2. Live Client Data API (local)

During a match, the in-game scoreboard and the item suggestions use the local Live Client Data API that runs on the player's own PC.

3. Data Dragon

Champion, item, rune and spell data and images come from Riot's public Data Dragon.

4. Riot Games API (server side only)

A scheduled job on our side builds the shared statistics. With a Riot developer key (kept as a secret, never inside the app) it uses:

  • League-V4: /lol/league/v4/entries/RANKED_SOLO_5x5/{tier}/{division} and /lol/league/v4/{tier}leagues/by-queue/RANKED_SOLO_5x5, to pick a small sample of ranked players;
  • Match-V5: /lol/match/v5/matches/by-puuid/{puuid}/ids and /lol/match/v5/matches/{matchId}, to read the final items and runes of recent ranked Solo/Duo games.

Only totals are kept (how often each item, rune page and champion appears and wins on Summoner's Rift and ARAM). No player names or ids are kept or published, and no per-player statistics are shown.

What GameMonitor does not do

  • It does not show ads, sell anything or ask for payment.
  • It does not read or change game memory or files, and it does not play matches for you.
  • It does not look up players whose names the game hides in champion select; they appear under placeholder names.
  • It does not use Riot Sign On and never asks for a Riot password.

Your data

Nothing leaves your PC unless you turn on sharing. Sharing is optional and off by default; when it is on, GameMonitor sends an anonymous record of each game it reads (champions, roles, results, final items, rune pages, patch and rank tier, never names or account ids) to our statistics server. You can turn it off at any time from the footer of the dashboard.
